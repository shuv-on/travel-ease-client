# Travel-Ease

[Travel-Ease](https://travel-ease-1dfb8.web.app/) is the most popular website for booking car.  


# Features 
- Booking car based on your choices. 
- You can also to-let your vehicle here. 
- Secure Booking System.
- Personal Dashboard.
- Modern User Interface. 

## Technology used: 
- React JS + Vite
- Express JS 
- MongoDB
- Firebase
- Vercel for backend hosting
- Using Axios for api calls 
## Packages includes:
- Framer motion
- React spring
- Date-fns
